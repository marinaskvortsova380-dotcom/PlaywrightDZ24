## 3. Команды запуска тестов

### 3.1. Запуск в фоновом (Headless) режиме (Основной режим)

Для запуска тестов в консольном headless-режиме с автоматическим формированием отчетов выполните команду:

```bash
# Через npm-скрипт из package.json
npm run cy:run:dz22

# Или напрямую через Cypress CLI
npx cypress run --config-file DZ22API/cypress.qauto.config.js
```

При необходимости запуска в определенном браузере (по умолчанию Electron):
```bash
# Запуск в браузере Chrome в headless-режиме
npx cypress run --config-file DZ22API/cypress.qauto.config.js --browser chrome --headless
```

---

### 3.2. Запуск в интерактивном графическом интерфейсе (Cypress Test Runner)

Для интерактивного запуска, визуального наблюдения за шагами тестов и отладки:

```bash
# Через npm-скрипт
npm run cy:open:dz22

# Или напрямую через Cypress CLI
npx cypress open --config-file DZ22API/cypress.qauto.config.js
```

**Шаги в интерфейсе Cypress**:
1. Выберите режим **E2E Testing**.
2. Выберите предпочитаемый браузер (например, **Chrome** или **Electron**).
3. Нажмите кнопку **Start E2E Testing**.
4. В списке спецификаций выберите `22api_interception_expenses.cy.js` для запуска.

## 5. Отчеты о тестировании (Mochawesome)

После завершения выполнения тестов в headless-режиме отчеты сохраняются в директории:
```
cypress/reports/dz22/
```
В ней формируются HTML-файлы с наглядными графиками, временем выполнения и детальным статусом каждого шага, а также JSON-артефакты для интеграции с CI/CD системами.

## 6. Резюме выполняемых шагов теста

1. **Шаг 1**: Авторизация $\to$ перехват `POST /api/cars` $\to$ добавление машины в UI $\to$ валидация статус-кода 201 $\to$ сохранение `id`.
2. **Шаг 2**: Запрос `GET /api/cars` через API $\to$ валидация статус-кода 200 $\to$ проверка наличия созданной машины по `id` и параметрам.
3. **Шаг 3**: Вызов кастомной команды `cy.createExpenseApi` $\to$ создание расхода через `POST /api/expenses` $\to$ проверка ответа (200/201).
4. **Шаг 4**: Переход в UI на страницу `/panel/expenses` $\to$ валидация созданного расхода (пробег, литраж, сумма).
